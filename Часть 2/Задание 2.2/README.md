# Задание 2.2: Восстановление данных в витрине dm.loan_holiday_info

## Описание проблемы

В витрине dm.loan_holiday_info отсутствуют записи для некоторых периодов эффективности строк.  
Источники данных для витрины:
- rd.deal_info - информация по сделкам клиентов
- rd.loan_holiday - информация о кредитных каникулах
- rd.product - справочник продуктов банка

## Выбранный способ решения

**Полная перезагрузка витрины (TRUNCATE + INSERT)**  
Обоснование: объём данных невелик, это гарантирует целостность и устраняет все пропуски.

## Файлы (выполнять в порядке нумерации)

| Файл | Назначение |
|------|------------|
| 01_загрузка_csv_в_rd.py | Загрузка актуальных CSV-файлов в слой RD |
| 02_анализ_пропущенных_данных.sql | Поиск записей, отсутствующих в витрине |
| 03_перестроение_витрины.sql | Полная перезагрузка витрины |
| 04_создание_процедуры_обновления.sql | Создание процедуры для автоматического обновления |
| 05_проверка_результатов.sql | Проверка корректности обновления |

## Порядок выполнения

1. Настроить файл config.py (указать параметры подключения к БД)
2. Запустить Python-скрипт: `python 01_загрузка_csv_в_rd.py`
3. В DBeaver выполнить по порядку SQL-файлы 02 → 05
4. Проверить логи в таблице LOGS.ETL_LOG

## Ожидаемый результат

- Все CSV-файлы загружены в слой RD
- Выявлены и устранены пропущенные записи
- Витрина dm.loan_holiday_info содержит актуальные данные
- Создана процедура для регулярного обновления
- Логи операций сохранены

## Примечание

Для работы скрипта необходим файл config.py из Задания 1.1 (с параметрами подключения к БД)
