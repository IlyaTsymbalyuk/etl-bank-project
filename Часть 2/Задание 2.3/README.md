# Задание 2.3: Исправление данных в витрине dm.account_balance_turnover

## Описание проблемы

В витрине dm.account_balance_turnover обнаружены расхождения:
- account_in_sum одного дня не равен account_out_sum предыдущего дня
- Это нарушает логику непрерывности остатков по счетам

## Решение

### Подход
1. Исправляем данные в источнике rd.account_balance
2. Перестраиваем витрину dm.account_balance_turnover

### Правила исправления
- Если account_in_sum и account_out_sum предыдущего дня отличаются, корректным считается account_out_sum предыдущего дня
- Если проблема в account_out_sum, корректируем его значением account_in_sum следующего дня
