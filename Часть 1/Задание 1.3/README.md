## Логика расчета

### Входной параметр процедуры
- `i_ReportDate` - первый день месяца, следующего за отчетным
- Пример: для января 2018 передаём `'2018-02-01'`

### Отчетный период
- `FROM_DATE` = первый день отчетного месяца (2018-01-01)
- `TO_DATE` = последний день отчетного месяца (2018-01-31)

### Источники данных
- Входящие остатки: `DM.DM_ACCOUNT_BALANCE_F` за день перед началом периода
- Обороты: `DM.DM_ACCOUNT_TURNOVER_F` за все дни периода
- Исходящие остатки: `DM.DM_ACCOUNT_BALANCE_F` за последний день периода

### Группировка
- По балансовым счетам второго порядка (первые 5 цифр номера счета)
- По главам из справочника `DS.MD_LEDGER_ACCOUNT_S`

### Валюты
- Рублевые счета: `CURRENCY_CODE IN ('810', '643')`
- Валютные счета: все остальные
