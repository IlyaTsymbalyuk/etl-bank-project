# Задание 1.2: Расчёт витрин оборотов и остатков

## Описание
Разработаны процедуры для расчёта витрин данных:
1. **DM.DM_ACCOUNT_TURNOVER_F** - обороты по лицевым счетам
2. **DM.DM_ACCOUNT_BALANCE_F** - остатки по лицевым счетам

## Файлы (выполнять в порядке нумерации)

| Файл | Назначение |
|------|------------|
| 01_create_dm_tables.sql | Создание таблиц витрин |
| 02_create_exchange_rate_function.sql | Функция получения курса валют |
| 03_procedure_turnover.sql | Процедура расчёта оборотов |
| 04_init_balance_20171231.sql | Инициализация остатков на 31.12.2017 |
| 05_procedure_balance.sql | Процедура расчёта остатков |
| 06_run_january_2018.sql | Запуск расчёта за январь 2018 |
| 07_check_results.sql | Проверка результатов |

## Логика расчета

### Витрина оборотов (DM_ACCOUNT_TURNOVER_F)
- `credit_amount`: сумма проводок по кредиту счета
- `credit_amount_rub`: сумма в рублях по курсу на дату
- `debet_amount`: сумма проводок по дебету счета
- `debet_amount_rub`: сумма в рублях по курсу на дату

### Витрина остатков (DM_ACCOUNT_BALANCE_F)
- Для активных счетов (char_type = 'А'): 
  `остаток = остаток_пред_день + дебет_обороты - кредит_обороты`
- Для пассивных счетов (char_type = 'П'): 
  `остаток = остаток_пред_день - дебет_обороты + кредит_обороты`

## Запуск в DBeaver
1. Выполнить файлы по порядку (01 → 07)
2. Проверить результаты через 07_check_results.sql
